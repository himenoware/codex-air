# Contributing

Codex Air is currently maintained by its owner while the native shell and connection boundaries are established. Please open an issue to discuss a proposed change before preparing substantial work. Do not submit copied Codex or codexRS source, private protocol implementations, credentials, or generated test fixtures.

The repository does not currently accept outside code contributions. Before that changes, the owner will publish a professionally reviewed contributor agreement and contribution policy that grants the project the commercial relicensing rights it needs while contributors retain copyright in their contributions. No casual CLA or implied assignment should be inferred from this document.

For local development, use the Windows scripts described in [README.md](README.md), keep UI code independent of transport types, and run the appropriate Cargo checks. Do not add new test files, test-only helpers, or fixtures without explicit owner approval.

Research about future connections must use official sources. ChatGPT subscription authentication through the Codex App Server and developer-platform Agents API credentials are separate paths.
